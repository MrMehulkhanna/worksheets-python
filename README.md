# Python worksheets

Solutions to three Python practice worksheets — small, self-contained programs, one per exercise.

| Worksheet | Topics | Examples |
|---|---|---|
| [`worksheet1/`](worksheet1) (15) | input/output, arithmetic, variables, loops | formatted poem output, swapping two numbers, sum of squares 1…N |
| [`worksheet2/`](worksheet2) (12) | lists, dictionaries, sets, tuples, strings | list operations, sum/product of a list, a 3-D list, set operations, random passwords, counting substrings |
| [`worksheet3/`](worksheet3) (7) | functions | range checks, reversing a string, counting upper/lower case, distinct elements, nested functions |

## Run

Python 3, no dependencies:

```bash
python3 worksheet1/8.py      # each file is one exercise; some read input from the keyboard
```
